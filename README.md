# 1688 以图搜图调研技能

使用用户上传或指定的图片，在 1688 搜索候选货源，并依据图片和商品详情比较同款可能性。

## 使用

在 Codex 中调用 `$1688-image-sourcing`，上传图片或指定本地图片路径，可指定输出目录。例如：

> 使用 $1688-image-sourcing 对我上传的图片进行 1688 以图搜图调研。

## 输出

生成独立的 `1688以图搜图调研.html`，表格包含嵌入的候选图片、商品链接、判断依据、待确认事项、价格和起订量。候选图片临时文件在嵌入并验证后清理，用户原图保留。外观相似不能证明同一工厂或规格完全一致。
