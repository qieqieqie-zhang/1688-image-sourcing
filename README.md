# 1688 以图搜图调研 Skill

根据用户提供的图片，在 1688 搜索候选货源，核对外观、结构和商品参数，并输出带商品图片的 HTML 调研表。

## 输入

- 用户上传的图片，或用户指定目录中的一张或多张图片；也可指定其他明确的图片来源。
- 可提供目标商品的尺寸、材质、功能等资料，以及希望保存结果的目录。技能不限定图片来自亚马逊。

## 处理过程

1. 确定用户希望搜索的图片；多图分别搜索并标明来源。图片选择不明确时先确认。
2. 使用浏览器打开 1688 的“以图搜款”，上传图片并进入结果页，记录搜索结果链接。
3. 查看结果图片，筛选候选货源，并逐个打开商品详情，比较造型、颜色、部件、功能、尺寸、材质和工艺，同时记录商家、商品链接、价格、优惠条件和起订量。
4. 按证据标注“高度疑似同款”“外观高度相似”或“无法确认”，写明一致之处、差异及待确认事项。搜索排序或平台标签只能作为线索；图片相似不能证明同一工厂或规格完全一致。包装尺寸与商品尺寸分别记录。
5. 将候选图片嵌入 HTML 调研表，核对图片和链接的对应关系；验证后清理临时下载的候选图片，不删除用户原图。无法取得的图片或信息会注明。

## 输出

```text
输出目录/
└── 1688以图搜图调研.html
```

HTML 包含搜索图片来源、结果页链接，以及候选商品图片、商家、链接、判断、依据、待确认事项、价格和起订量。图片嵌入页面，无需保留单独的候选图片文件。价格和库存可能变化，以实际页面及结算为准。

## 使用与依赖

将本仓库作为技能目录安装到支持 `SKILL.md` 的工具中，上传图片或提供图片路径，并说明需要调研的商品。技能使用 [web-access](https://github.com/eze-is/web-access) 访问浏览器，需先安装和配置；`SKILL.md` 中的 web-access 路径应按实际安装位置调整。访问 1688 可能需要登录或验证。
